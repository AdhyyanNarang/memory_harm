# Character Profiles

Pre-generated user profiles sourced from:

**Williams, Carroll et al. (2025).** "On Targeted Manipulation and Deception when Optimizing LLMs for User Feedback." *ICLR 2025.* arXiv:2411.02306v3.

Repository: https://github.com/marcus-jw/Targeted-Manipulation-and-Deception-in-LLMs

## Files

- `therapist/vuln_*.json` — Vulnerable condition profiles (character traits imply gullibility/overdependence on chatbot)
- `therapist/normal_*.json` — Normal condition profiles (character traits imply independence)
- `reference/` — Original config files from the paper's repo (for reference only)
